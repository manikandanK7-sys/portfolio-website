# Manikandan K — Digital Marketing Portfolio

Personal digital marketing and multimedia portfolio website of **Manikandan K**, showcasing digital marketing projects, skills, video editing, graphics design, and analytics experience.

## 🚀 Live Demo & Deployment
- **GitHub Pages**: [https://manikandank7-sys.github.io/portfolio-website/](https://manikandank7-sys.github.io/portfolio-website/)

---

## 📌 Features
- **Modern Responsive Design**: Fully responsive across mobile, tablet, and desktop devices.
- **Dark / Light Theme Support**: Adaptive glassmorphism UI with smooth transitions and glowing accents.
- **Hero & About Section**: Professional summary, background, and quick facts.
- **Skills Matrix**: Digital marketing, Video Editing (CapCut/Premiere), Photoshop, and Data Analysis.
- **Projects Showcase**: Case studies and digital marketing campaigns.
- **Courses & Experience**: Certifications, education, and career milestones.
- **Contact**: Quick contact information and social links.

---

## 🛠️ Built With
- **HTML5 & CSS3** (Vanilla CSS with Custom Properties & Glassmorphism)
- **Google Fonts** (Sora & DM Sans)
- **JavaScript** (Lightweight interactivity & smooth scrolling)

---

## 💻 Running Locally
To view the site locally, clone this repository and open `index.html` in any modern web browser:

```bash
git clone https://github.com/manikandanK7-sys/portfolio-website.git
cd portfolio-website
# Open index.html in your browser
```
